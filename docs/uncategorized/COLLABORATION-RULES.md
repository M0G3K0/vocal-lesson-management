# 協働ルール（暫定）

## 合意の扱い

- AIの提案は、ユーザーが明示的に合意するまで未合意とする。
- 沈黙や曖昧な返答から合意を推測しない。
- 合意した内容と未決定の内容を区別して記録する。
- 提案への合意は、その内容への合意を意味する。後続の操作まで許可されたとは解釈しない。

## 作業と反映の指示

- AIは、作業に着手する前に目的・進め方を提案し、ユーザーの指示を待つ。
- いつ内容を記録・反映するかはAIが自動判断せず、ユーザーの指示に従う。
- 指示された場合も、その対象と範囲を越えて作業しない。

## GitHub Issue

- AIは、指示されない場合は、GitHub Issueを作成・編集・コメント・Close・Reopenしない。
- Issueに記載する文面の案はチャットで提示できる。GitHubへの記入はユーザーが行う。

## ドキュメントとGitHub Projects

- 半永続的な決定事項を文書化するときは、ユーザーの指示に基づいてAIが文書作成・更新を支援する。
- GitHub Projectsの更新は、ユーザーから指示された範囲で行う。
- commit、push、Pull Request作成・Mergeなどは、個別に明示された操作だけを行う。

## 今後の仕組み化

ここに記載した取り決めを技術的に強制する方法は、別途検討する。現時点では、この文書に運用上の取り決めを記録する。

## 未決定事項

- AIとの取り決めを、口約束に頼らず強制する具体的な仕組み。
